# Stage 5 deploy, labeling template and the CFPB directional split (June) (CU stance and sentiment scoring)

> June 2026 stance work: the labeling template and re-run recipe, the CFPB directional split in the workbook, and the Stage 5 overhaul and deploy. Part of [[2026-06-feature-cu-stance-and-sentiment]] (project [[melange-systems]]).

## Template location and re-run recipe (source `cu-sentiment-template-location`, 2026-06-30)

- The CU press **sentiment/stance** R pipeline and its live data live in `C:\Users\pgoff\OneDrive\Desktop\Draft Systems\` (NOT `Melange Systems`, which holds only Excel mirrors + scored outputs like `CU_Press_Stance_Tone.xlsx` / `cu_press_releases_scored.xlsx`). The code root is the actor [[draft-systems-r-pipeline]].
- **The labeling template fed to R = `cu_stance_label_set.csv`** (Draft Systems), generated by `sample_for_labeling.R` (writes `text_snippet` + a blank `human_label` column to fill support / oppose / neutral); consumed by `measure_stage5.R`, `run_retrain_human.R`, `run_accuracy_push.R`, `fulltext_backfill.R`, and passed to `finetune_debate.py --labels`.
- `cu_stance_label_set.xlsx` (copies in BOTH folders) is a human-review **mirror** (tabs "To Rework" / "Done (locked)"); R never reads it. Its `split` column (train/test/batch2) differs from the CSV's (train/test/exclude) even though both hold the same 552 rows + identical labels (164 pre_label != human_label).
- Stance = fine-tuned Political DEBATE; tone = Lexicoder LSD2015 (`run_stage5.R` / `stage5_lsd.R`); LSD parsed by `parse_lsd.R` (no quanteda; its RcppParallel segfaults on R 4.6.0).
- **Re-run after editing labels** (R at `C:\Program Files\R\R-4.6.0\bin\Rscript.exe`, NOT on PATH; CPU-only, ~1 hr/epoch): (1) `Rscript run_retrain_human.R` fine-tunes on `cu_stance_label_set.csv` human_labels -> `debate_finetuned/`, default `CU_FT_EPOCHS=3`, **rewrites the CSV's `split` col** (seed 42; labels preserved; back it up first), writes `cu_stance_accuracy_report.txt`; (2) `CU_S5_DEBATE_MODEL=debate_finetuned Rscript run_stage5.R` (**env var REQUIRED**, else stage 5 silently re-scores with the BASE model and the retrain is wasted) writes `cu_press_stance_tone.csv` + `cu_press_value_by_category[_wide].csv`; (3) `python make_standalone.py` rebuilds `CU_Press_Stance_Tone.xlsx` from those CSVs (+ `all_press_release_index.csv`); stage 5 does NOT write the xlsx itself. Base + large DEBATE models are cached in the HF hub, so run offline (`HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`). Prior fine-tune baseline to beat: acc 0.851 / kappa 0.760 on the 87-row held-out test.
- Press classification stays the user's domain: `human_label` is the override column; never relabel. Related memory: `press-classification-user-domain`, `moneyball-model-config` (see `2026-07-rfc-melange-architecture-system-of-record`).

## CFPB directional split in the workbook (2026-06-25; source `project_cfpb_directional_split`)

Split the single "CFPB Issues & Structural Reform" legislative topic into two directional topics in the Moneyball model, driven by Paul's tagged `CFPB Bills` tab: Direction +1 Reduce (49 bills) / 0 Neutral (6) / -1 Expand (5). Structure (uniform with the other 17 topics): **CFPB Restrain** = +1 bills, reused the in-place block cols 99-106 (CU:DB), renamed, legislative weight **+0.5**; extended its R&A!D formula range from 4-col `CU:CX` to 5-col `CU:CY` to include the regular Co-Sponsor column (was unlabeled/omitted; Paul confirmed the fix). **CFPB Reach (-)** = -1 bills, NEW appended block cols 145-152 (EO:EV), outside the Excel Tables; legislative weight **-1.0** (Paul chose the heavier penalty on expansion). Neutral excluded. Avg + Success-Rate columns deliberately 0 (weight-0 by design; see `feedback_spreadsheet_consult_on_errors`); only Sponsor (0.286) / OrigCosp (0.143) / Cosp (0.0714) weighted. Aggregation = sum of DecayWeight per member/role from the Sponsor + Original Co-Sponsor + Co-Sponsor Interactions sheets, joined to CFPB Bills by bill No. (Title col), filtered by direction; 100% join; verified 3,198 cells, 0 mismatches. **Result:** Reach members penalized (Al Green No. 119, McGarvey No. 142, Whitehouse No. 509); Restrain champions strong (R. Williams No. 4, Hill No. 7, Barr No. 16); Warren No. 14 (Reach penalty on legislative but committee influence keeps her high: influence-not-alignment, see `influence-vs-alignment-axes`). **COM GOTCHA (environment as of 2026-06-25):** this PowerShell-Excel COM environment threw InvalidCastException ("cast Double/Object[,] to String") on scalar AND 2D-array NUMERIC `.Value2` writes; workaround = write numbers as invariant-culture numeric STRINGS via `.Formula`; also `Remove-Item $var` in a script was blocked by a path guard. (Superseded practice: writes no longer go through COM, resolution 5; kept because it explains the June workbook edits.) **Open (then):** the `Legislative Score - Raw` matrix is regenerated by `congress_member_scraper.R` (`project_moneyball_integrated_scraper`); the split was workbook-only, so the R script needed the same Restrain/Reach split or a re-run would overwrite it.

## Stage 5 overhaul and deploy (June 2026; sources `project_stance_sentiment_overhaul`, `project_moneyball_deploy`)

The full engineering record (artifacts, environment constraints, validation numbers, deploy gotchas) is in the actor note [[debate-stance-model]].
