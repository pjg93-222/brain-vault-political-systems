## CU press-release scraper (`cu_press_release_scraper.R`)

### Second scraper added 2026-06-10
Same folder. Scrapes PRESS RELEASES from every 119th-Congress member's OWN .house.gov/.senate.gov site (NOT congress.gov - no Cloudflare machinery needed; plain httr GET + Chrome UA works) back to 2020-01-01, then scores each credit-union-relevant release +1/0/-1 toward credit unions per the user's "Moneyball ACU" outline (`C:\Users\pgoff\Downloads\Moneyball_ACU_Search_Outline.docx`). 5 checkpointed stages (`pr_checkpoints/`): roster (legislators-current.csv incl. `url` column) -> press-index DISCOVERY (homepage "press" links + common CMS paths; pagination scheme probed among qpage0/qpage1/PageNum_rs/path-page; failures go on a Coverage sheet for `MANUAL_PRESS_URLS` fixes) -> index crawl (title/date/url; date found by climbing <=4 anchor ancestors) -> full text (`FULLTEXT_MODE` "topical" fetches only ACU-topic titles; "all" fetches everything) -> scoring. Scoring = generic tone words inside CU-mention sentences + weighted pro/anti-CU phrases (tax-status attacks etc.) + stance x position on the outline's SUPPORT/OPPOSE bill table (`BILLS` df; names match any congress, 119th numbers only for releases >= 2025-01-03; default stance is SUPPORT unless a narrow oppose-cue appears - bare "against" deliberately excluded). Subtle fixes that must survive edits: `norm_bill_refs()` collapses "S. 110"/"H.R. 507"/"x.J. Res. N" before sentence splitting (abbreviation periods otherwise shatter citations); two-digit years parsed with explicit %m/%d/%y (tryFormats %Y reads "25" as year 25 AD -> sanity-window NA). Offline test suite `test_cu_scoring_offline.R` (27 checks, all passing; set `CU_PR_NO_AUTORUN=1` to source without running). Outputs: `cu_press_releases_scored.xlsx` (Scored Releases / Member Summary / Coverage) + 2 CSVs. NOT yet run live against member sites (as of 2026-06-10).

## Press scraper: fallback chain, third-party sources and coverage work

### 5-step fallback chain for MANUAL_PRESS_URLS members (added 2026-06-12)
Discovery tries: static page -> WordPress REST API (`/wp-json/wp/v2/posts`, scheme `wpjson`) -> sitemap.xml (scheme `sitemap`) -> chromote render (`js_render=TRUE`) -> Wayback CDX URL index (scheme `cdx`). Crawl branches on those schemes; Stage 4 for cdx/js members requires body AND date (soft-404 guard - Indigov sites serve homepage content at dead URLs without redirecting) and falls back per-URL: static -> chromote -> exact Wayback snapshot via `wayback_snapshot_url()`.
- **Why:** the Indigov CMS family (luna, kiley, maxmiller, landsman, yakym, torres, etc.) cloaks sitemaps (403), has no API, renders listings only behind a bot wall - Wayback CDX is the only archive source. Dean-family (`?id=GUID`) sites parse statically once `PRESS_PATH_RX` allows single-digit months (/2026/6/slug). WordPress family (clarke, brownley) gives full dated archives via wp-json (Clarke: 2,367 releases).
- **How to apply:** verified members never re-fetch (checkpoints). `retry_failed_checkpoints()` re-discovers manual members when `MANUAL_PRESS_URLS` was edited AND their crawl is empty. Probe-script pattern: set `CU_PR_NO_AUTORUN=1`, source the file, redirect `CHECKPOINT_DIR` to tempdir. Related notes: `project_congress_scraper`, `user-r-environment`, `project_moneyball_model`.

### Coverage fix (2026-06-18): archive fallback for auto-discovered members
The fallback chain used to fire ONLY for MANUAL_PRESS_URLS members - AUTO-discovered members whose live index rendered a handful of items (`scheme="none"`) were stuck on page 1 (audit: 47 members <=10 index items, e.g. britt.senate.gov = 6 of a multi-year archive; 367/533 ended all-zero in the press scores). Also broadened `TOPIC_BROAD_EXTRA_RX` (regulator/Dodd-Frank/FDIC/OCC/prudential/veteran/servicemember/community development/financial institution); for max completeness set `FULLTEXT_MODE<-"all"`.
