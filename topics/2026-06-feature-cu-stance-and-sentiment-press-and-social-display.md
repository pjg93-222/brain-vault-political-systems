### Ops lessons (the expensive ones)

1. **`make_member_desk.py` can FAIL and still leave outputs behind.** It wrote `dashboard_exclusion_reconciliation.json` then raised, so the bundle/HTML stayed STALE from an earlier run; the stale artifact was read and numbers "verified" that were three builds old. **Always check the exit code; never trust an output file's contents without checking its mtime.**
2. **`dashboard_integrity.postflight` is fail-closed and reconciles every display row to a declared source** (`source_rows == sum(components)`), and fingerprints the desk dials. Adding display rows trips `IntegrityError` unless the new source is declared; adding a dial trips the same-input determinism check unless added to the fingerprint. The guard caught a real accounting gap.
3. **The LIVE tree was edited by mistake** (it is a worktree on *another* session's branch, `claude/cfpb-sentiment-recorrection`). The diff was verified as a pure insertion before reverting. Confirms `live-tree-branch-state-2026-07-14`: always target the worktree path explicitly, and `MONEYBALL_ROOT=<live>` + `DESK_OUT=<scratch>` is the safe combo (worktrees DO isolate data; `codex-executor-lane-2026-07-18` is right, change-control law 7 is stale).
4. **Regenerating live from WORKTREE code trips `dashboard_integrity`, correctly.** The fingerprint hashes `fec/make_member_desk.py` as it exists in the live tree, so running worktree code against live data = "declared inputs unchanged, output changed" -> `IntegrityError: same dashboard inputs produced a different semantic bundle`; it also leaves a landmine (the state file maps live's OLD code to the new bundle, so the next chain run from live's own code fails too). **The code must be IN the live tree before regenerating it.** Merge first, then regenerate: the fingerprint changes honestly and the guard self-heals.
5. **`make_combined.py` does NOT check whether the desk build succeeded**: when the desk raised, it rebuilt `Moneyball.html` from the STALE desk HTML. Check the desk exit code first (same failure family as lesson 1).
