# Census CD and Ballotpedia CU-influence scrapers (Congress R scrapers)

> The Census congressional-district scraper of 2026-06-16 and the Ballotpedia 119th-Congress CU-influence scraper of 2026-06-17/18: their metrics, the Ballotpedia locked design and its status after the live double-check of 2026-06-17/18. Part of [[2026-06-feature-congress-r-scrapers]] (project [[melange-systems]]).

## Census CD scraper (`census_cd_scraper.R`, 2026-06-16)

Lives at `C:\Users\pgoff\OneDrive\Desktop\Draft Systems\census_cd_scraper.R`. Pulls mortgage, income, finance/transport industry shares, migration (residence 1yr ago), median age, poverty, and small-business (CBP) metrics and writes `Congressional_District_Census_Data.xlsx` with ONE data sheet `State_and_CD` + `Variable_Dictionary`. `build_metrics(level)` runs the same logic for level "cd" (`for=congressional district:*` `in=state:*`) and "state" (`for=state:*`); the two levels are STACKED (the user explicitly wanted them NOT joined): 52 state rows (carrying both U.S. Senators) + 437 CD rows (carrying the Representative) = 489 rows x 37 cols. A `Geography_Level` column ("State"/"Congressional District") marks each row; the 25 metric columns hold each row's own-level value (Senator cols blank on CD rows, Representative/District_Code blank on State rows).

Built against the **Census Bureau API** (httr/jsonlite/writexl), NOT by scraping data.census.gov's ag-grid: the user's original CSS selectors (`.ag-row-hover`, `.ag-row-position-absolute:nth-child(N)`) are hover/screen-position based and do not work in automation. Each highlighted cell was mapped to a variable code; the dictionary sheet records every mapping.

Key operational facts (non-obvious, verify before reuse):
- The Census API **requires an API key** (2024+); keyless requests redirect to `missing_key.html`. The user's key is stored in `C:\Users\pgoff\OneDrive\Documents\.Renviron` as `CENSUS_API_KEY` (that path is what R's `path.expand("~")` resolves to here). (Key material not recorded.)
- Table `C25027` (mortgage by age, collapsed) was **discontinued after 2012**; use detailed `B25027` instead - "35-64" = sum of `_004E.._007E` (35-44, 45-54, 55-59, 60-64).
- County Business Patterns (CBP) **is** available by congressional district (`/2020/cbp`, `ESTAB`); a handful of districts are NA (disclosure-suppressed / territories).
- 2024 ACS 1-year uses **119th-Congress** district boundaries; 2020 CBP uses 116th - a minor cross-vintage mismatch.
- The opening burst of API calls can be throttled (returns an HTML page, not JSON); the fetcher retries with backoff and treats any non-`[` body as retryable.
- Member names come from the @unitedstates congress-legislators CSV. Working URL is `https://unitedstates.github.io/congress-legislators/legislators-current.csv` - the documented `theunitedstates.io` host now redirects to an HTML page (do not use it). Join reps by USPS state + district int (at-large/delegate = district 0; Census CD codes "00"/"98" map to 0). A few members have a blank `full_name` (e.g. CA-01, NJ-11) so fall back to first+last. ~4 House seats are currently vacant -> labeled "Vacant / no seated member". DC/PR have no senators.
- B08126 ("means of transport to work BY INDUSTRY") is a commute-mode x industry cross-tab (99+ vars), NOT flat. The user's nth-child selectors map row N -> variable `_0NN` (verified on B25091 rows 8-11 and C25027 row 4). Their "transportation" metric was corrected to FINANCE: `B08126_024E` = "Car/truck/van drove alone: Finance, insurance & real estate" as a % of all workers (`_001E`). (Their literal nth-child(23) = `_023E` = "drove alone: Information"; they meant finance, so `_024E`.) Switch to `_009E` for finance-all-modes if needed.
- Write is lock-resilient: if `Congressional_District_Census_Data.xlsx` is open in Excel / locked by OneDrive, the write fails with "Permission denied" and the script falls back to a timestamped copy. Tell the user to close the file to regenerate under the canonical name.
- Validators in the same folder: `_robustness.R` (27-check battery) and `_verify_names.R` (name join + district -> state cross-check); both auto-pick the newest `Congressional_District_Census_Data*.xlsx`. Related notes: `user_r_environment`, `project_congress_scraper`.

## Ballotpedia 119th CU-influence scraper (`ballotpedia_119th_cu_scraper.R`, 2026-06-17/18)

`ballotpedia_119th_cu_scraper.R` scores every 119th-Congress member for Credit-Union influence and writes a 3-sheet Excel: **Members** (one clean row per member, one column per metric: Member, Party, Chamber, State, District, Election_Average, Years_Served, Committee_Positions, Committee_Leadership, Caucus_Positions, Caucus_Leadership, Party_Leadership), **Detail** (bioguide/url/`*_detail` audit columns), **Reference** (rubric). Distinct from the congress.gov scraper and the press scraper.
- `SKIP_ELECTIONS <- TRUE` builds the full 537-row table in ~1 min with NO per-member Ballotpedia fetch (Election_Average = NA); committees from YAML + caucuses from CSV need no browser. To generate: source, then `SKIP_ELECTIONS <<- TRUE; run_scrape(resume=FALSE)` then delete `bp119_checkpoint.rds` so it does not poison a later real elections run. Latest output: `Ballotpedia_119th_CU_Influence_<stamp>.xlsx`.
- Caucus name -> roster matching (`score_caucuses_for` / `.name_refers_to` / `.tok_eq` / `.NICK_GROUPS`): last name + >=1 other token matched against roster full_name+first+nickname+last, with prefix tolerance (Randy/Randye) AND a nickname map (Bob/Robert, Dave/David, Jim/James, ...). Audited all 38 caucus leaders -> all resolve except David Scott (GA) and Mikie Sherrill (NJ Gov) who correctly are not on the current feed.

### Locked design (CONFIG block, all editable)
- Roster + `years_served_since_2020` + tenure come from the @unitedstates congress-legislators JSON (authoritative term history), NOT Ballotpedia. The `ballotpedia` id in that data gives exact page titles, avoiding name disambiguation. Flip `PREFER_BALLOTPEDIA_TENURE` to use Ballotpedia "Assumed office" instead.
- COMMITTEES come from the same project's `committee-membership-current.yaml` (authoritative, structured, has exact role titles + subcommittees), NOT scraped from Ballotpedia - verified live (709 raw / 682 CU-relevant memberships across ~230 members; French Hill = HFSC Chair, Tim Scott = Senate Banking Chair). `COMMITTEE_SOURCE <- "ballotpedia"` reverts to HTML scraping. Ex-officio subcommittee seats (auto-assigned to full-cmte chairs/ranking) are EXCLUDED by default via `COUNT_EX_OFFICIO <- FALSE` so chairs are not double-credited. Ballotpedia is now only used for ELECTIONS (vote%) + caucuses (before MEDSL, see below).
- Electoral avg = weighted mean of general-election vote% over 2016/2018/2020/2022/2024; GOP-presidency midterm (2018) weighted 2x, all else 1x. Senate adds `electoral_avg_state_combined` = mean of both senators' averages (6-year term).
- Scoring (restructured 2026-06-17 into 3 separate metrics): (1) **`cu_committee_positions`** = +1 per relevant committee/subcmte seat (flat count); (2) **`cu_committee_leadership_score`** = graded sum Chair 1.0 / Ranking 0.8 / Vice Chair 0.6 / Vice Ranking 0.4 / Member 0.2 (unchanged); (3) **`cu_caucus_leadership_count`/`_score`** = LEADERSHIP ONLY - Chair 1.0, Co-Chair/Vice Chair 0.8, rank-and-file members score 0 and are NOT counted (so full caucus rosters no longer affect the score - only CMO officers matter; Army member rows in the CSV are now inert). Party leadership: Speaker & Pro Tempore 1.0 / Maj Ldr 0.8 / Min Ldr 0.6 / Maj Whip 0.4 / Min Whip 0.2.
- **BUG FIXED 2026-06-18:** `party_caucus_for()` matched `PARTY_LEADERSHIP` by LAST NAME only (first-name disambiguation fired only when >1 leader shared a surname), so all 5 sitting "Johnson"s inherited Speaker Mike Johnson's 1.0. `PARTY_LEADERSHIP` now carries a `bioguide` column and `party_caucus_for` matches on bioguide. Re-run to regenerate clean output. This output also feeds the Moneyball model Sub Layer AW:BA - see `project_moneyball_model`.
- CU-relevant committees = curated regex list (`CU_COMMITTEE_PATTERNS`); caucuses = `CU_CAUCUSES` (scrape caucus pages for rosters) with a trusted manual CSV override (`manual_cu_caucus_members.csv`).
