## Context

**What this is.** A research-grade program (documented in `big5_methods.md`, main tree) that scores each member of the ~533-member roster on O, C, E, A and ES (emotional stability; N = -ES) and asks, per trait, whether the measure is valid (convergent, discriminant, known-groups, reliability) against criteria independent of the text. It is part of [[melange-systems]] (Moneyball CU-influence model); its engine touch-point is the receptivity layer (`receptivity_layer.py`: susc_z = .40*A + .30*N - .20*C - .10*E, feeding susceptibility/cascade/persuasion, NOT the influence rank; ranks md5 `cce0c5a6` / `c99e8cf7fd04e499` stayed identical through every N/A-slot change). Rulings and gates are Paul's (Paul Goff); the audio branches of the program connect to Audio and speech lane and [[melange-audio-pipeline]]; the look/holdout rules to [[single-look-holdout-discipline]]; evidence and "never say 5/5" discipline to Verification and evidence standards.

**Instrument glossary (from the sources).**
- **Lexical** = `big5_traits.json` (Ramey-synth + Empath + fitted SMOreg); v1 text; stays only as N-source/weights candidate at times.
- **Blue** = behavior-calibrated text instrument (`big5_lexcal_v2.py` -> `big5_v2.json`, v3 hybrid `big5_v3_hybrid`; the Blue behavioral instrument look of 2026-07-09 is a separate evaluation).
- **Pink** = LLM item-level read `big5_llm_opus.json` (`fec/big5_llm.py`, de-identified chunks, Opus), 469 members; display-only (no engine reads it).
- **RKH** = Ramey/Klingler/Hollibaugh published congressional personality estimates (text-derived, Mairesse-LIWC; 147-member overlap with current roster).
- **Gold** = *Personality on the Hill* appendix panels (129 Senate insiders + 125 academics) in `big5_senate_expert_gold.json`.
- **`reactivity_z`**, **`affective_n.json`**, **`coop_v2`/`cooperation_v2_z`**, **`hearing_antag*`** = the behavioral/affective N and A slots and criteria described in the records.
- **MEM / MEM_N / MEM_A** = pinned eligible-roster sets for the looks (MEM=456, MEM_N=201 at round 4, MEM_N 216/250 after MS NOW, ~270 per 2026-07-16 count; MEM_A=290/291).

## Record 4: Hearing antagonism / defiance criterion, 2026-07-10 (`hearing-antagonism-2026-07-10`; last modified 2026-07-11; session 2599f411; also sessions clever-elbakyan, local_bdf50296)

**Why this matters (the strategic correction Paul forced):** the whole interview -> `reactivity_z` -> MEM_N>=250 gate only serves ES/N (`reactivity_z` IS the behavioral Neuroticism proxy; N and ES are the SAME axis, opposite poles; a text-N vs reactivity pass = the independent ES corroboration ES has never had). Hearing-antagonism is the FIRST A lever raised all session that isn't cosponsorship. Also: the text Big-Five ALREADY ingests hearings+floor (`b5_behavioral_instrument` `load_corpus` `group_concat(text) from speeches`, all sources), so adding hearing TEXT doesn't fix ES (validity problem, reads E, not quantity) or grow MEM_A (cosponsorship-gated, 73/76 non-MEM already have >2000 chars). Hearing ANTAGONISM (events, not text) is the only new channel.
