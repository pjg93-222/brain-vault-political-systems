## CFPB sentiment re-correction (2026-07-15; sources `cfpb-sentiment-recorrection-2026-07-15`)

### The overshoot

**The overshoot Paul flagged 2026-07-15 = the 2026-07-07 `policy_force` CFPB neutral-pin.** In `cu_valence_registry.json`, families `cfpb_institution` (defund / gut / save / defend the cfpb, funding / staff / vought) and `cfpb_general` (bare "cfpb") were flagged `policy_force` valence 0; both stacks (`fec/tweet_stance_stack.py` ~L125, `fec/press_stance_stack.py` ~L125) FORCED any support/oppose to `neutral`. This over-neutralized the whole CFPB agency-existence axis: on the 9,465-tweet corpus, 2,179 policy-force hits (cfpb_general 1,986 + cfpb_institution 193) -> 1,696 pinned neutral -> **1,582 tweets had a clear composed direction destroyed**. The registry's own note said it was NOT validated "until a fresh gold sample is adjudicated on the new axis."

**Paul's 41 hand-labeled tone corrections** (`Documents\CFPB and Sentiment Analysis Correction.xlsx`, 7-point scale, spans 30 tweets + 11 press, keyed by title/text only) ARE that fresh gold, and adjudicate the axis as DIRECTIONAL: **attacking/defunding CFPB = pro-CU/support (+), defending/praising CFPB = anti-CU/oppose (-)**. New gold WINS conflicts with older gold (Paul explicit).

### The fix (branch `claude/cfpb-sentiment-recorrection`, commits 6843591 + 00ea7b4)

- **Part A (relax pin, both stacks):** keep neutral ONLY when the composed read (`api_read` / `f_flat`) is itself non-directional; else trust the composed direction: `s = f_flat if f_flat in ('support','oppose') else 'neutral'` in both `press_stance_stack.py` and `tweet_stance_stack.py`. Registry entries keep `policy_force:true` as the family marker; the CODE honors the relaxed rule; the `_doc` note was updated.
- **Part B (overlays, top precedence, applied LAST):** NEW `tweet_stance_overrides.json` (mechanism added to `tweet_stance_stack`) + existing `press_stance_overrides.json` (11 press). Both keyed by quorum_id/url + text/title_contains. (Later hardened: tweet overrides are `quorum_id`-keyed, NOT `text_contains`, which overmatched 149 tweets = BUG-A; press overrides use `title_contains` + normalized-URL.)
- **Validated vs the 400-row tweet gold:** sign acc **0.540 -> 0.809 (+27pp)** (0.825 at 82138c9); over-neutralized 156 -> 24; **neutral-gold preserved 60/62 -> 60/62 = NO overcorrection** (false-directional held at 2); Paul's 30 tweet corrections 2/30 -> 30/30; 11 press 11/11.
- **Propagated:** `build_media_blend` + full `run_pipeline` re-ran; 447/533 ranks moved, all directionally correct (Barr/Meuser press pillar UP pro-CU; Warren/Blumenthal DOWN anti-CU). Backups `*.PRE-CFPBFIX-*`.
- **1 audit item (NOT a fix bug):** codex's `OVERALL_OPPONENT_CUTOFF=-1.60` (user-directed 2026-07-15, `moneyball_core.py`) manufactures >= 1 Opponent; the media-pillar shift re-normalized Durbin above it -> 0 opponents -> `audit_full.py:42` "overall Opponent rung populated" FAILS (101/102). Re-tuning that cutoff is Paul's dial decision (resolved by the scale shift below).
- **The prior REJECTED approach (do NOT repeat):** a generic verb-count CFPB directionality lexicon over whole text (3 good / 43 bad flips, "cannot tell sponsor from critic"). The relaxed-pin fix avoids that because it trusts the COMPOSED direction (which respects genuine neutrals), not a blanket phrase flip.
