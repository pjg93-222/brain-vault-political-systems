## DE-047 — Restoring an omitted rare class's probability from a class_w
Date: 2026-09-29
Approach: Restoring an omitted rare class's probability from a class_weight='balanced' random forest without undoing the weights (Luna CU-geography stratified-scaling coverage repair, 2026-09-29)
Failure mode: The repair copied the balanced forest's raw mass for children code D and dwelling code G into the deployed completion. It flipped 1,154 blank fills to D or G; on the reused B/test/stress checks it made 158 D and 104 G predictions with none correct, and accuracy, log loss and Brier score all got worse for both fields on all three checks (overall -0.021/-0.026/-0.027 pp).
Root cause: Balanced class weights give every class the same effective prior, so the forest's probability for a class with 0.009% (D) or 0.011% (G) prevalence is inflated about 3 x 10^4 in odds: the raw mass is a uniform-prior posterior, not a natural-prior one.
Would reconsider if: The restored mass is prior-corrected first (multiply the raw class probabilities by observed class prevalence and renormalise), as the 2026-09-29 prior-corrected repair does, or the base model was fitted without class weights.
