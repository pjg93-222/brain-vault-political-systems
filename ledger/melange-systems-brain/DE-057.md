## DE-057 — Asserting an async route job's first answer in a test
Date: 2026-10-03
Approach: A test asserted that the first answer from starting an async route search is "queued" or "searching".
Failure mode: The worker thread can finish before the first answer is built. Over 30,000 measured starts that happened 0.4% of the time unloaded and 0.9% under load, so the test failed intermittently (test_a_lost_cheapest_route_reaches_the_page_as_a_search_error_over_http).
Root cause: A race between the job's worker thread and the response to the start request.
Would reconsider if: Never. Poll to a terminal state and assert the terminal status (fixed in fb3f874c2, landed in 3366a7840).
