## DE-035 - Returning a status from a PowerShell function that also runs a native command
Date: 2026-09-19
Approach: `function Invoke-X { & $Runner $Arguments; return 'online' }` with `$mode = Invoke-X ...`.
Failure mode: Everything the native command writes to stdout is part of the function's output, so `$mode` became an Object[] of python's lines followed by 'online', the build receipt field became an array, and the cross-reference's output vanished from the build log. `$mode -eq 'online'` on that array returns the matching element, so a comparison still "passes". Stubs that print nothing cannot see it; `| Out-Host` fixes the type and loses the lines from a Tee-Object log.
Root cause: PowerShell functions return their whole success stream.
Would reconsider if: Never. Pass the status out by [ref] (or a script-scoped variable) and leave the call unassigned, and test with a runner that prints.
