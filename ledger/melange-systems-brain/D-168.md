## D-168 — One release channel and four package types
Date: 2026-10-11
Status: ACTIVE — decided by Paul 2026-10-11 (rulings 5 and 6; the manual-v1 clause is plan item R5, adopted on plan approval).
Decision: ops/release.py (plan, run, resume, status) is the single release action. One run updates the platform repo with Geo tags, CI images to private GHCR, and draft GitHub releases; a release manifest signed on the laptop (ssh-keygen -Y sign, namespace melange-release, ed25519 key in ssh-agent) that the VPS verifies before deploying image digests (downgrades refused, automatic rollback on failure); the Netlify desk; Mentat Pocket; and the launcher shortcuts. Four package types: install kits (code only), encrypted data snapshots (restic), reader downloads (behind Access), and offline dependency bundles. v1 releases are run by hand; an automatic data release after the weekly refresh is deferred until Paul asks for it.
Context: Paul's goal is to send an update once and have every platform receive it. Release ids are CalVer vYYYY.MM.DD.N with state under %LOCALAPPDATA%\Melange\releases\<id>\state.json; steps are idempotent. Gates before a run: no pipeline, weekly or Mentat lane lock held; the allowlisted paths clean with each HEAD at the released ref ([[ledger/melange-systems-brain/DE-031|DE-031]]); fec/tests/run_tests.py with 0 FAILED in the live tree and the Mentat unittests passing; the refresh COMPLETE with the receipt hash equal to deploy\index.html. Data restores are rehashed against the signed manifest ([[ledger/melange-systems-brain/DE-053|DE-053]]). Source: plan C:\Users\pgoff\.claude\plans\we-are-going-to-dapper-sunrise.md, approved by Paul 2026-10-11; Paul's rulings were relayed in the orchestrator's brief for this brain update, so no verbatim quote is available to this lane (same as [[ledger/melange-systems-brain/D-140|D-140]]).
Rationale: One action prevents the platforms drifting apart. A laptop-signed manifest that the VPS verifies means a GitHub compromise cannot ship code to the server. Running v1 by hand keeps every outward step under Paul's eye before any automation is trusted.
Reversal condition: Paul asks for the automatic data release after the weekly refresh (R5 lapses for that step only), or for a second release path.
