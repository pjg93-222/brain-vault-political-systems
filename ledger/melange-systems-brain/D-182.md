## D-182 — Image licence policy: OS-package licences report-only
Date: 2026-10-12
Status: ACTIVE — decided by Paul 2026-10-12 (his answer "OS-package licences report-only"). Amends [[ledger/melange-systems-brain/D-169|D-169]] and [[ledger/melange-systems-brain/D-181|D-181]] for the images stage only.
Decision: In the security gate's images stage, trivy licence findings on OS packages (Debian GPL, LGPL and similar) are reported, not blocking. Licence findings on language packages (pip, npm) that we add still block when the licence is forbidden or unknown. The images are private and never redistributed.
Context: [[ledger/melange-systems-brain/D-181|D-181]] made the images stage block only on fixable HIGH/CRITICAL vulnerabilities but left trivy's licence class blocking; the Debian 13 base images carry GPL and LGPL packages by design, so every image would have failed on licences of packages we did not choose and cannot change. Vulnerability, misconfiguration and secret findings are unchanged: fixable HIGH/CRITICAL vulnerabilities, misconfigurations and secrets still block. Paul stated no reversal condition for this ruling; the one below was written by Claude from the ruling text. Source: Paul's answer in this session, relayed in the orchestrator's brief for this brain update.
Rationale: Paul's call. OS-package licences come with the Debian base and the images stay in Paul's own accounts, so reporting them loses nothing; the licences of the Python and npm packages we choose to add remain a real control and stay blocking.
Reversal condition: An image is distributed outside Paul's accounts, or a language-package licence slips through the gate.
