## D-180 — Collectors proven by record/replay
Date: 2026-10-12
Status: ACTIVE — decided by Paul 2026-10-12 (his answer "Collectors proven by record/replay").
Decision: Each containerized collector is proven by replaying responses recorded on Windows and producing records identical to the Windows host's; only after that proof does it run live.
Context: [[ledger/melange-systems-brain/D-173|D-173]] names the Melange collectors among the compute lanes and requires each lane to prove its outputs against the Windows host before it replaces that host's job; this ruling sets the method of that proof for collectors. Any workbook or SQLite output a collector writes is compared at the [[ledger/melange-systems-brain/D-177|D-177]] standard. Paul stated no reversal condition for this ruling; the one below was written by Claude from the ruling text. Source: Paul's answers in this session, relayed in the orchestrator's brief for this brain update.
Rationale: Paul's call; no further rationale was given. Replaying the same recorded responses isolates the container's code from the live source, and no collector runs live until its proof passes.
Reversal condition: A collector's replayed records cannot be made identical to the Windows records (it stays on Windows until Paul rules again), or Paul drops the replay requirement.
