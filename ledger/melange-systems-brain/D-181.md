Decision: All images move from Debian 12 (bookworm) to Debian 13 (trixie) bases pinned by digest. The security gate's images stage (trivy) fails on HIGH/CRITICAL findings that have a fix available (--ignore-unfixed); unfixed findings are reported, not blocking.

[[ledger/melange-systems-brain/D-172|D-172]] names a python:3.12.x-slim-bookworm base for the serve images; that base moves to trixie under this ruling. Paul stated no reversal condition for this ruling; the one below was written by Claude from the ruling text. Source: Paul's answers in this session, relayed in the orchestrator's brief for this brain update.
Rationale: Paul's call. Fixable findings are actionable by moving to a base that has the fix, whereas findings with no upstream fix cannot be cleared by us, so blocking on them would stall every release; they stay visible in the report.
Reversal condition: A trixie base cannot be built or run for an image (for example a pinned package has no trixie build), or Paul rules a different scan threshold.
