## D-050 - A report build survives losing the network: the cross-reference falls back to saved evidence
Date: 2026-09-19
Status: ACTIVE - `f8908029a` on codex/mentat-crypto.
Decision: build_industry_report.ps1 retries an ONLINE cross-reference that exits non-zero once with --offline; if that succeeds the build continues, warns, and records cross_reference_mode = offline_fallback in its receipt (online and offline are the other values). A failure that also fails offline stops the build as before. -CrossReferenceMaxRequests and -CrossReferenceOffline travel through every launcher and the worker spec with unchanged defaults.
Context: Every build, cache hits included, runs the cross-reference with up to 100 live requests, and no caller could say otherwise. run_cross_reference.py has no exit code separating a network failure from a logic failure, so the retry itself decides the class.
Rationale: The published workbook is the accounting of record and the cross-reference an auditable side computation ([[ledger/melange-systems-brain/D-040|D-040]]), so losing the network must not block publication, while a real tool failure is computed the same way offline and still stops the build.
Reversal condition: a fallback is observed masking a logic failure that the offline path does not reproduce.
