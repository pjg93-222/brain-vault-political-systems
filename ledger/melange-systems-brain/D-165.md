## D-165 — Hosting topology
Date: 2026-10-11
Status: ACTIVE — decided by Paul 2026-10-11 (rulings 2, 7 and 8; plan approval).
Decision: The laptop keeps all compute (chains, collectors, Excel COM, Edge, claude CLI, R jobs). A rented US Linux VPS (Ubuntu 24.04, about 16 GB RAM) serves the apps from signed, encrypted snapshots pushed from the laptop. Melange on the server is the static desk plus lobby pages only; the live staffer console stays on the laptop (hosting it needs a 32 GB server). Mentat is a read-only console. Terrier is one hosted app per district (co05, or05, ct01) that opens walk lists and door-knock recording to that district's invited staff; the server becomes the master copy of field results, on a separate writable state volume with a nightly age-encrypted backup pulled to the laptop and then to Carbonite.
Context: Today nothing propagates: Melange is local plus a local mirror ([[ledger/melange-systems-brain/D-139|D-139]]), the desk goes out by manual Netlify drop, and every server is loopback-only by design ([[ledger/melange-systems-brain/D-140|D-140]]); Docker, the Netlify CLI, restic, cloudflared and gitleaks are not installed. Hosted mode in each app is opt-in behind explicit env vars; local default behavior stays byte-for-byte unchanged. The live staffer console needs 9.6 GB RAM; hosting it would also need 8841 read-only work (no identity-DB writes, crawler off, receipt write off, PureWindowsPath at 6 sites). Source: plan C:\Users\pgoff\.claude\plans\we-are-going-to-dapper-sunrise.md, approved by Paul 2026-10-11; Paul's rulings were relayed in the orchestrator's brief for this brain update, so no verbatim quote is available to this lane (same as [[ledger/melange-systems-brain/D-140|D-140]]).
Rationale: Compute stays where the data, Excel COM, Edge and the key stores are, so a server compromise does not reach the collectors, API keys or the signing key (which never leaves the laptop). Terrier is the one app that writes on the server, because field recording happens there; its state lives on its own volume that snapshot pushes never touch, and a nightly encrypted pull plus a restore test cover the single-copy risk.
Reversal condition: Compute-plane containerization (proposal v1 Layer 2) lands, or Paul approves hosting the live console.
