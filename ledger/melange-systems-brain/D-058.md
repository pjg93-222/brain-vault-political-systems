## D-058 — The brain is mirrored off OneDrive and every commit pushes itself
Date: 2026-09-19
Status: ACTIVE
Decision: The Project Brain repos are mirrored outside OneDrive: the toolkit and each brain (melange-systems-brain, folder-brain, pilot-brain) has a remote named mirror at C:\Users\pgoff\GitMirrors\<name>.git, and a post-commit hook in each repo pushes every commit there.
Context: Paul 2026-09-19: 'set up the brain mirror', after the live-tree reconcile lane reported that the Project Brain repos had no remote. Bare mirrors created under C:\Users\pgoff\GitMirrors (the folder Carbonite backs up): project-brain.git, melange-systems-brain.git, folder-brain.git, pilot-brain.git; all branches pushed, mirror HEAD set to master.
Rationale: OneDrive sync is not a backup (CONSTRAINTS) and the brain is the only continuity between sessions; until 2026-09-19 it had no remote at all. The Melange code mirror had just been found eleven days stale because pushing it was a manual step, so the brain mirror pushes itself from a post-commit hook. The hook cannot fail or delay a commit: both pushes end in || true and the script exits 0.
Reversal condition: The GitMirrors folder leaves Carbonite's backup set, or the hook is seen delaying or breaking a brainctl commit; then push from brainctl flush instead. The hook lives in .git/hooks, which git does not version: after any re-clone re-create it, and check git ls-remote mirror master against local master at close-out.
