## DE-034 - Publishing a rule that requires a new index version without building the index
Date: 2026-09-19
Approach: Bump the version a reader requires (R/fec_transfer_graph.R accepts only the current transfer index version) and leave the rebuild to "whoever runs the refresher next".
Failure mode: Nothing rebuilds a stale transfer index and the refresher has no production caller. From 09-10 until 09-19 every report build took the stale branch and published every Conditional estimate as 0.00. The only signals were `warn`-severity quality checks; no export guard covers transfers, so nothing stopped publication.
Root cause: A version gate that degrades to zeros instead of refusing, plus a derived cache with no owner.
Would reconsider if: Never. A change that bumps a required cache version rebuilds the cache in the same lane and says so in its commit, as [[ledger/melange-systems-brain/D-049|D-049]]'s did.
