## D-169 — Fail-closed security gate on everything leaving the laptop
Date: 2026-10-11
Status: ACTIVE — decided by Paul 2026-10-11 (plan approval, plan item R2). Extends [[ledger/melange-systems-brain/D-096|D-096]], which gates the vault only. (partially amended 2026-10-12: [[ledger/melange-systems-brain/D-181|D-181]] moves the image bases to Debian 13 and makes the images stage fail only on HIGH/CRITICAL findings that have a fix available; the other stages are unchanged.; [[ledger/melange-systems-brain/D-182|D-182]] makes OS-package licence findings report-only in the images stage.)
Decision: ops/security_gate.py (stages export, images, packages, all) must pass before any export push, image, package or upload leaves the laptop. It fails closed: a missing tool or a stale vulnerability database fails the gate. Exceptions live in ops/security/exceptions.toml and each needs a reason, Paul as approver, an expiry (30 days or less for HIGH and CRITICAL findings) and a brain D-id; an expired exception fails the gate.
Context: [[ledger/melange-systems-brain/D-096|D-096]] gates only the vault's outbound notes; nothing gated code, images or data leaving the laptop. Planned checks: gitleaks plus an exact-match check against the real local secret values (names only are printed); pip-audit, npm audit and osv-scanner; bandit and semgrep with three project rules (non-loopback bind outside hosted mode, forwarded headers used for auth, unpickling without a sidecar); Terrier manage.py check --deploy with an assert that hosted mode has no local admin; trivy on images; data-leak checks (denied extensions, 5 MB ceiling, PII regex sample, planted canaries, locked files must parse as encrypted). Source: plan C:\Users\pgoff\.claude\plans\we-are-going-to-dapper-sunrise.md, approved by Paul 2026-10-11; Paul's rulings were relayed in the orchestrator's brief for this brain update, so no verbatim quote is available to this lane (same as [[ledger/melange-systems-brain/D-140|D-140]]).
Rationale: Private repos on GitHub Free and Pro get no code scanning or push protection, so the local pre-push run is the real control. Failing closed on a missing tool or stale database stops the gate from passing by silence.
Reversal condition: Paul retires the gate, or GitHub-side scanning becomes available and he rules it sufficient.
