## DE-013 - Treating a tool_result as proof a backgrounded agent finished
Date: 2026-08-27
Approach: GLASSEYE derived fan-out completion by matching any `tool_result` carrying the dispatch's
`tool_use_id` (fanout.ps1:106), and detected backgrounding by looking for `"run_in_background":true`
in the dispatch input (fanout.ps1:101).
Failure mode: FALSELY GREEN. For a backgrounded dispatch the `tool_result` is the SYNCHRONOUS launch
acknowledgement - `toolUseResult` = `{"isAsync": true, "status": "async_launched", ...}` - which lands
~2.4 s after dispatch. Measured: three subagents emitted `agent.completed` 350 ms, 1,028 ms and 476 ms
after their `agent.started`, `duration_ms: -1` on every event, while ground truth showed all three
still running four minutes later.
Root cause, and it is an INVERSION worth remembering: the Agent tool BACKGROUNDS BY DEFAULT, so the
caller writes `run_in_background` only when OVERRIDING to foreground. The key's ABSENCE means
backgrounded - the exact opposite of what the predicate assumed. 0 of 18 dispatches in the sampled
transcript carried the key at all, so the `task.*` branch that would have handled this was DEAD CODE
from the start.
Why it mattered more than a mislabel: `metaloop.ps1 -Action finish` refuses a terminal receipt whose
fan-out coverage is unverifiable, and that refusal is the mechanical tooth for lane law 4. With every
pair closing ~400 ms after it opened, coverage always read complete, `open: 0` meant nothing, and a run
could take a clean finish receipt over work still in flight. This is the falsely-green twin of [[ledger/melange-systems-brain/DE-011|DE-011]]'s
always-red gate - both failure modes the anti-vacuity contract names, one each, found the same day.
Would reconsider if: never. Classify from what the transcript OBSERVED, never from what the caller
requested. Fixed by [[ledger/melange-systems-brain/D-017|D-017]]. Second-order lesson: a predicate over an OPTIONAL flag inverts silently
when the default changes, and nothing in the code says which way the default points - prefer a signal
that is present in both states.
