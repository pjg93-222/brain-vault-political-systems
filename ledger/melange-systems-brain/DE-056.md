## DE-056 — Replacing += with sum() in a bit-identical float copy
Date: 2026-10-03
Approach: Writing a "row-only" copy of closeness_math.pair() for the cold-path speed round that accumulates exposure with sum() instead of the original's += loop.
Failure mode: On Python 3.12, sum() over floats is compensated and differs from a += loop in the last bit. 36 pairs differed on the seeded test world, which breaks bit-identical neighbour rows and can reorder near ties under [[ledger/melange-systems-brain/D-082|D-082]].
Root cause: Python 3.12 changed float sum() to compensated summation; a copy that must be bit-identical has to keep the original operation order.
Would reconsider if: Never for a bit-identical copy. Keep the same operation order (+=); the guard is test_control_the_comparison_is_sensitive_to_float_operation_order (people-network latency lane, commit d37c811bd, landed in 3366a7840).
