## D-177 — Equivalence standard for containerized compute: content-level
Date: 2026-10-12
Status: ACTIVE — decided by Paul 2026-10-12 (his answer "Equivalence standard for containerized compute: content-level"). Amends [[ledger/melange-systems-brain/D-173|D-173]]'s "byte-identical" wording. (partially amended 2026-10-13: [[ledger/melange-systems-brain/D-196|D-196]] replaces the tolerated-difference clause for workbook formula comparison with a rank-gated tolerance: continuous numeric cells may differ by at most 1024 ULP, only when every rank, percentile and threshold matches exactly in the same run; the rest of this entry stands.) (procedure amended 2026-10-13: [[ledger/melange-systems-brain/D-201|D-201]] sets the "Lighter" proof standard for the remaining parity work, one Windows reference run plus one container run; the equivalence rules here are unchanged.)
Decision: Workbooks and SQLite stores are compared by content: every cell value and every table row must be identical. ranks_python.json, dashboard_data.json, bipartisan.json and the Terrier bundle zip stay byte-identical. The only tolerated difference is proven-harmless floating-point noise of a few ULP, and only on continuous cells that feed nothing discrete; ranks, percentiles and thresholds must match exactly.
Context: [[ledger/melange-systems-brain/D-173|D-173]] required each compute lane to prove byte-identical outputs (ranks, desk data, workbooks) against the Windows host before it replaces that host's job. Byte identity is impossible for workbooks and SQLite stores even Windows to Windows, because every save stamps metadata. This amends [[ledger/melange-systems-brain/D-173|D-173]]'s wording for workbooks and SQLite stores only; the rest of [[ledger/melange-systems-brain/D-173|D-173]] stands, and the byte gates that [[ledger/melange-systems-brain/D-172|D-172]] names (ranks_python.json and dashboard_data.json) are unchanged. Source: Paul's answers in this session, relayed in the orchestrator's brief for this brain update.
Rationale: Paul's call. Byte identity cannot be reached for these two file types, so content equality is the strictest standard that can be met; every output that can be byte-identical stays byte-identical, and anything discrete (ranks, percentiles, thresholds) must match exactly.
Reversal condition: A content-equal output is found to change any downstream number.
