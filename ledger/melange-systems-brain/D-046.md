## D-046 — Committee scores become a derived chain producer; the honors binding scopes to the sheets it writes
Date: 2026-09-18
Status: ACTIVE — committed `ce594a79e` on branch `claude/melange-members-section-fixes-6613db` (worktree), for main commits `25f604288`, `11a34e215`, `482d24df0`.
Decision: The workbook's Committee Data score columns are DERIVED, not hand-maintained — fec/engine/committee_scores.py recomputes them from each row's seat text as a chain step before compute_pillars, so the displayed tier marker is authoritative and a tier edit can never silently disagree with the published influence number. This closes the gap [[ledger/melange-systems-brain/D-042|D-042]]'s own Open item flagged (cached score/seat text could "disagree silently" with no recompute step). The honors workbook publication binds only the region it writes, so an edit to any other sheet no longer blocks the chain while an edit inside an honors sheet still refuses by name.
Context: This lane hit both on 2026-09-17 and 2026-09-18 while shipping the committee tiers ([[ledger/melange-systems-brain/D-042|D-042]]) and had to repair each by hand; Paul's instruction was "Fix".
Rationale: Both were silent-wrong-number shapes: the first published a score that disagreed with the visible seat text, the second made a correct safety guard block all work instead of the work it protects. Both proofs shipped before landing: the "Small Business forced [Highly]" override ([[ledger/melange-systems-brain/D-042|D-042]]'s own preserved quirk) deleted after proving it inert against the new producer; the honors data-loss hole closed with a sticky original_exact flag.
Dials: fec/engine/committee_scores.py --check / --write; HONORS_WORKBOOK_SCOPE=region (default) / legacy.
Reversal condition: the legacy dial restores the whole-file honors binding byte-for-byte; the committee producer can be removed from CHAIN, at the cost of returning to a hand-maintained column.
