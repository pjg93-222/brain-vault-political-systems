## D-239 — Admin console extends the native admin dashboard, with a desktop launcher
Date: 2026-10-18
Status: ACTIVE
Decision: The admin console for Terrier, Mentat and Melange extends the native admin dashboard (ops/desktop/server/admin_dashboard.py); Docker is reached from the host through a fixed-argv docker CLI allowlist (ps, inspect, logs, restart, compose pull and up at the release's pinned digests, system df), with no new image, no socket proxy and no Docker socket in any container; a desktop launcher (Desktop and Start-menu "Melange Admin" shortcuts) opens it.
Context: Decided by Paul, 2026-10-18. Plan finding 5 judged a new melange-admin image behind a third-party Docker socket proxy over-built; Paul: "Extend native dashboard, I need a desktop launcher for it". Source: plan C:\Users\pgoff\.claude\plans\c-users-pgoff-documents-platform-install-fizzy-pizza.md (ruling R2, items 4 and 5). The existing dashboard authenticates with a 60 s one-time #bootstrap link that yields a hashed bearer plus CSRF, loopback only, strict Host and Origin checks, 8 h auto-shutdown. Relates to [[ledger/melange-systems-brain/D-181|D-181]] (a new image is a new scan surface) and [[ledger/melange-systems-brain/D-175|D-175]].
Rationale: A socket proxy is a new pinned image and scan surface and is still root-equivalent once restart and update are allowed; a host-side fixed-argv allowlist needs neither, and the one-time-link login suits a Paul-only local tool better than a stored password.
Reversal condition: Someone other than Paul needs the console, or it must be reachable off this laptop (the hosted admin design and its auth are then reopened).
