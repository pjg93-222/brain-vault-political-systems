### The split-role colour law (2026-08-06; load-bearing for any restyle)

In the five surface producers a hex is chrome or data by its *occurrence*, not its value; a per-hex find/replace silently destroys data encodings.

- Confirmed split-role: `#58a6ff` (link chrome AND canvas network-edge stroke), `#1f6feb` (control fill AND rolebadge), `#fbbf24` (selection ring AND TIERCOL tier-1), `#fff` (CSS text AND canvas allocation/seed rings), and the **greys**: `#8b949e #9ca3af #9098a4 #94a3b8 #6e7681 #7d8694 #e6edf3 #3a414b` all carry data roles (TIER_COLORS unclassified, STCOL T and N, ELCOL.n, antagCol neutral, TRK_COL, the white coalition-state ring, INDUSTRY_FAMILY derivations). Mapping four distinct greys onto one token collapsed STCOL T and N into the same colour.
- `rgba()` / `rgb()` literals exist too (54 of them, 28 distinct) and a `#hex` regex misses all of them; an rgba inherits its base hex's status.
- Any future restyle must classify per-occurrence and end with a byte-diff of every JS colour map against HEAD.
- **Verification that works** (`scratchpad/final_audit.py`): decode HEAD and worktree as UTF-8 and compare non-ASCII inventories (mojibake check); diff colour multisets and require every delta to be an authorised chrome substitution; byte-compare `STCOL PTCOL TIERCOL TRK_COL PILL INDUSTRY_FAMILY BILL_LOBBY_SECTOR_COLORS`. Final state: 732 authorised deltas, **0 data-colour deltas, 8/8 structures identical**.
- **Contrast** must be checked against every surface, not just `--bg`: first pass `--faint:#8D8673` (4.83 on bg) failed AA at 3.65 on `--panel-hover`; corrected to `#9D9784` (worst 4.53). The token declaration is not the whole fix: 36 raw literals still carried the old value.
- **CVD result** (`scratchpad/cvd_check.py`): gold chrome is NOT more confusable with data than the old blue was (deltas -0.8 deuteranopia, -0.3 protanopia); the OLD blue chrome sat dE 9.0 from the *Democrat* party blue; gold moves the nearest collision off a party colour.
- **Binding design rule:** gold is never a small saturated mark (no gold dot/swatch/legend square); borders use the low-chroma warm ramp `#433317` / `#564019`, never saturated gold. This defuses `#c2862a` (pillar demographic) sitting at dE 3.0 from `#BB8525`.
- **Font:** no webfont embedded (surfaces are self-contained and near a page-size ceiling). Stack `"Century Gothic","Tw Cen MT",Futura,"Avenir Next","Segoe UI"` (Century Gothic and Tw Cen MT are installed on this box). Chrome only; `#mname` and the dynamic industry/organization/member `h2`s are excluded via `:not()` so real names are never uppercased or letterspaced.
- **Mentat glyph (APPLIED 2026-08-06, Paul approved):** viewBox `0 0 128 208`, path `M108 20 L64 64 L28 104 L64 144 L20 188 M64 64 L100 104 L64 144`, fill none, stroke `#EECD5C`, miter join, miterlimit 6. Stroke-width 18-19 at wordmark size, **24 at favicon size** (thinner vanishes at 16px). The favicon is a self-contained data URI: the `#` MUST be `%23` or the URI truncates at the fragment. Lobby branding also changed to Melange.
- SETTLED: `.sbar i` keeps its blue -> green gradient (adjudicated an indicator, not chrome: it fills quantitative score bars).
- Retheme deploy recipe: the live tree sat on a DIFFERENT branch (`claude/cfpb-sentiment-recorrection`) and the worktree had no `dashboard_data.json` / `ranks_python.json` (inputs live only in the live tree), so run the WORKTREE's producers with `MONEYBALL_ROOT` set to the live tree (worktree code, live data, live outputs).
